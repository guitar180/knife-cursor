# 🗡️ Knife Cursor

> **Win11 光标太无聊？FPS 对枪被颗秒后手感冰凉？桌面缺个动态挂件？以上问题一步解决！**

这是一个基于 **Electron + TypeScript** 的 Windows 桌面光标动作引擎。它可以将你的系统鼠标指针替换为完全自定义的序列帧动画，并支持全局快捷键触发宏动作。

![演示动图](这里放一张你的GIF图片链接)

## ✨ 核心特性

- **🎯 多动作管理器**：内置 UI，一键扫描本地文件夹，按需加载不同素材。
- **⭐ 动态待机循环**：不按键时循环播放呼吸/摇摆动画，按快捷键触发专属检视动作。
- **👻 系统光标接管**：底层拦截并替换原生 Windows 光标，随时开关。
- **🛡️ 极限 Z-Order 霸屏**：无视任务栏、开始菜单遮挡，永远浮在最顶层。
- **💾 独立参数调节**：每套动作可独立调整大小、动画时长、跟手松紧度与 XY 轴偏移。
- **🚑 极限容错**：配置损坏自动修复，支持一键恢复出厂设置。

## 🚀 快速开始

1. 前往本仓库的 **[Releases]** 页面下载最新的 `Knife-Cursor-x.x.x-x64.zip`。
2. 解压后，**右键 -> 以管理员身份运行** `knife-cursor.exe`。
3. 在右下角托盘右键打开**设置**，扫描你的素材文件夹，开始绑定按键吧！

> ⚠️ **必看说明**：
> 1. **权限要求**：为了捕获全局按键与接管光标，软件**必须**以管理员权限运行。
> 2. **安全拦截**：未购买数字签名，首次运行若遇 Windows SmartScreen 蓝屏拦截，请点击**“更多信息” -> “仍要运行”**。
> 3. **杀软误报**：因涉及底层监听，部分杀软可能拦截，代码全开源，请放心放行。

## 🎨 自定义素材规范

- 文件夹内需包含序列帧：`frame_000.png`、`frame_001.png` 等（务必补零）。
- 背景必须为透明 PNG，尺寸建议 `256x256` 或 `512x512`。
- 详细的打包与开发技术原理，请参阅 [DEVELOPMENT.md](DEVELOPMENT.md)。
